# 路线图与项目边界

更新：2026-10-01。这里维护方向与范围；具体工作状态只在[任务清单](02-tasks.md)维护。

## 项目目标

Agent Usage 在本机读取已有记录，提供按时间、渠道、模型与仓库查看的 Token 用量和 API 等价费用估算。原始日志与索引留在本机，无需账号或上传正文。

## 已交付的基础能力

### 用量与数据

Codex 会话日志、ZCode SQLite、DSH 多帧会话日志、OpenCode 消息库和项目 JSONL 进入统一事件口径。内存统计、SQLite 增量索引和静态导出有三路一致回归。普通范围统计全部已选来源，Codex 限额窗口只统计 Codex 来源。

### 费用与维护

内置价目、自动来源和手动字段覆盖共同形成有效价目。前后端共用模型解析；缺价模型保持可见，免费规则与最低费率估算分别标记。现有模型可自动更新，有完整证据的 OpenAI USD 文本模型可自动补录；手动价格与汇率优先。

Claude 已有 17 个内置版本与 Anthropic 价格更新，官方日期快照按明确映射计价。缓存写入采用带提示的 5 分钟场景；DSH 非零写入已核实并修正，ZCode 缓存包含关系仍待上游证据。

### 使用与交付

看板提供周期对比、排序、搜索、日期与时区、刷新控制、中英文和深浅主题。静态 HTML 内嵌数据与资源，可在 `file://` 离线打开，固定导出时的用量与价目。

## 当前边界

- 费用是 API 等价估算，不是实际账单、订阅扣费或服务商配额消耗。
- 不用缺失的日志推算历史请求；缺少明细时保留不确定性和估算标记。
- OpenCode 当前支持 v2 消息表；旧 JSON 树、旧 message/part 布局和独立子代理渠道未接入。
- DSH 与 OpenCode 不提供 Codex 限额数据。
- 新模型自动发现限于满足严格证据条件的 OpenAI USD 文本模型；其他提供商的已有价目更新与新模型发现是不同能力。
- 无法忠实表达的时段、节假日或二维输入/输出档位价格保留现有费率，不把简化猜测记作来源核验成功。
- 原生浏览器缩放、真实来源的全部 UI 路径、缓存 TTL 和 ZCode 输入语义等边界，按任务清单和验证记录区分已测与待测。

## 后续工作如何进入计划

先核实数据语义和可复现的行为，再决定实现范围与验收方法。新增来源应同时覆盖发现、分类、指纹、标准事件、索引、限额排除、模型分组和导出；新增价格来源应先确定提供商、币种、单位、档位与失败保留策略。

维护候选不自动成为施工任务。具体新功能经确认后进入 02，涉及较大设计时新增专项计划；完成后将有效规则合入现行专题，计划转入归档。
