# TPS 任务交接模板（执行时复制，不是验收记录）

本页是[实施总计划](../2026-10-04-model-tps-implementation-plan.md) §4 的填写格式。每张卡保存到本次 `docs/validation/<运行日期>-perf-metrics/<runId>/handoffs/Mx.y.md`；模块集成者再建 `Mx.md`。状态只能是 `DONE / NEEDS_REVIEW / BLOCKED`，不能用“代码已写完”替代证据。

## 单卡 `Mx.y.md`

```md
# Mx.y <卡名> — 交接

任务号 / 状态：Mx.y / DONE|NEEDS_REVIEW|BLOCKED
任务卡：<实施计划中的精确链接>
前置报告及其 SHA-256：<逐项列出；未满足就说明>
运行目录 / Git HEAD / dirty 状态：<同 run.json；若已变化注明>

改动文件及开始/结束 SHA-256：
- <文件>：<开始；新文件写“无”> → <结束>；<写入归属/并行冲突核对>

实现的接口与关键行为：
- <接口签名、字段口径、对应任务卡验收项>

实际运行的检查：
- <完整命令> → exit <数值>；证据 <本 run 内相对路径>；<测试数/fixture 摘要>

未测项、失败、降级与契约偏差：
- <逐项列出；没有写“无”；绝不把未执行写成 PASS>

交接给下一卡：
- <已冻结接口/文件摘要/必要重新检查/待决项>
```

## 模块 `Mx.md`

```md
# Mx <模块名> — 集成审核

模块状态：DONE|NEEDS_REVIEW|BLOCKED
受测 Git HEAD / dirty 文件摘要 / runId：<与 run.json 核对>

子卡矩阵：
- Mx.1：<状态>；报告 <链接>；验收核对 <实际证据>
- ...

模块归属文件最终 SHA-256：<逐项列出>
接口兼容与跨卡行为：<至少一条成功和一条失败路径的实测结果>
实际重跑命令与退出码：<仅填本模块集成者自己运行的命令>
未解决冲突、未测项、风险：<逐项列出；没有写“无”>
下一模块可使用的产物：<接口、fixture、schema/版本与摘要>
最终审核者须重点复核：<具体 SQL/代码/页面路径>
```

`M0.md` 必须逐一确认四个来源探测的输入指纹和 M0.6 决议；`M3.md` 记录迁移 SQL/替换事务；`M4.md` 记录两生产路径与两个 API；`M7.md` 记录跨 rollout 失效矩阵。最终审核者的意见另存 `review.md`，不覆盖执行者原 handoff。任何后续修复另开新 run 或追加带时间的复核记录，并更新受测文件摘要。
