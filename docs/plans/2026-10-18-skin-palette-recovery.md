## 一次性纠正角色语义

- `spotlight.tinted-surface`：改为 `kind: decorative / required: false / threshold: null`。光晕没有独立信息、前景或稳定边界；保留原状态和截图，在视觉评审中检查干扰。其影响范围内的必要文字没有获得豁免。
- `chart.detail-fill`：保留 `kind: graphic`、ID、选择器和两个状态；改为 `required: false / threshold: null`。`public/app.js` 的 `renderBarListHtml` 为每一条同时输出可见名称和数值；同一渲染器的 `chart.model-bar` 已按冗余图形处理。仅此精确结构适用，不能推广到时间分布堆叠图、图例色块、坐标、无可见等价文字的图形或焦点。
- 两者不是自动 PASS：新浏览器记录应走现有 NA/视觉分支。条形仍须肉眼清楚，并保留文字与数值的必要测量。历史缺测保持原状。
- roles/policy 同步 38 → 39；更新相关契约与必要回归。不得修改文字 4.5、必要图形/焦点 3 的数值门槛，不改全局缺测规则、Assessment schema 或 verifier。

依据：[WCAG 非文字对比说明](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html) 的 Required for understanding：装饰效果、已经用可见文字提供同等标签和值的图形，不必独立满足图形比值。此决定与原方案“不把所有强调色用途套同一标准”一致；不是一次全站合规声明。
