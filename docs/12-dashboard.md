## 使用场景与布局基准

本地看板读取 PC 上的用量记录，主页与各弹窗面向桌面鼠标键盘操作，以 16:9 高分辨率大屏为主要设计场景。手机使用这些页面不属于当前需求。桌面显示缩放、浏览器侧栏、并排窗口和短窗口仍会影响实际可用空间，相关适配按桌面窗口处理。

下文的窄窗口行为描述现有 CSS 在空间受限时的表现，不表示独立的手机产品定位；历史验收中的手机尺寸截图保留其原始测试语境。后续界面工作的验收基准见[开发说明](03-development.md#界面设计与验收基准)。生成的分享图片另按接收端阅读场景设计，不要求生成它的本地页面也采用手机布局。

## 时间范围与时区

今日、本周、本月、全部按选择的 local/UTC 解释；本周为自然周。最近范围中的上个月是完整自然月，本年从 1 月 1 日到当前时间。“上一个5h”从上一轮五小时额度实际开始到下一轮实际开始，保留完整起止时间和分钟时长。“上一个7d”（内部请求值为“上周”，英文 Last 7d）从上一轮周额度实际开始到下一轮实际开始，保留完整起止时间和分钟时长。提前换轮和到期后延迟使用都按真实边界计算；到期但没有下一轮时，不切换上一轮。两者都不能解释成普通日历周期。

`5h / week` 在当前 Codex 五小时和每周限额窗口之间切换。没有可信边界或没有选中 Codex 来源时，不凭空推算对应限额能力。当前五小时图按半小时、当前每周图按连续24小时显示；上一个5h只显示有用量的半小时，跨日标签带日期，最后一段截止到下一轮实际开始；上一个7d只画有用量的日历日期，日期按选择的 local/UTC 解释，即使跨年也不合并成周或月。

当前和上一限额窗口排除不消耗套餐用量的 `codex-auto-review`，包括用量卡片、费用、时间图、模型/仓库明细、纪录与性能统计；普通范围保留其实际运行量，费用为 0。价目列表显示“官方免费”，不报缺价；规则与来源见[计价说明](11-pricing.md#模型解析与免费规则)。Codex 日志记录的真实限额百分比不据此重算。

日期控件按起止范围选择，支持反向点选、清除和 Escape。时区下拉位于刷新框内右上角，复用最近范围菜单材质；支持方向键、Home/End、Enter、Escape、Tab、外部点击和选后焦点返回。local/utc 选择持久化，上海本地显示 GMT+8；切换同时影响范围解释与上次刷新时间。长范围可自动合并为周/月时间桶，图表文字和 tooltip 标明实际覆盖区间。

## 用量、费用与周期对比

输入总量、缓存命中、缓存未命中、输出和推理使用[统一口径](10-data-sources.md)。费用按[当前有效价目](11-pricing.md)展示；模型显示名称统一小写，原始标识仍用于统计和解析。

时间分布的“按模型”“按花销”按每个时间槽内的用量或费用排序，柱内由下到上从大到小堆叠；悬浮详情由上到下从小到大排列，与柱子从上到下的大小顺序对应。混合币种按图表采用的汇率折算后比较，详情金额保留原币种。数值相同时按模型原始名称排序。

模型与仓库支持搜索、周期对比和适用的 New Record。全部范围没有上一周期，不显示对应纪录徽标。仓库表首先展示本地 Git 仓库，这条规则高于所有周期用量和手动升降序；普通目录在后。

仓库表在 Git/非 Git 各组内、模型表在全表内，默认依次按今日 → 本周 → 本月 → 全部降序，平手时按名称和稳定原始标识；手动表头三态切换以所选周期为组内主键，平手按其余默认周期决胜，恢复默认后重新使用四级顺序。

## 来源与模型分组

扫描目录的“编辑”提供导入和来源选择入口，顶部不再重复放置导入按钮。来源选择控制哪些目录进入统计，不改变目录类型；内部 main 的徽标显示为 codex。普通范围按产品整合渠道，限额范围保留细分，详见[渠道口径](10-data-sources.md#渠道展示与归组)。Codex、ZCode、DSH、OpenCode 的计价模型按固定 harness 顺序分组；同一价目键先到先得，避免重复编辑。一个 harness 分区为空可能是模型已被前面的分区认领，不等于没有该来源用量。

近一个滚动日历月内使用的缺价模型仍显示在在用列表，不因无法解析到价目而消失；退出与覆盖率规则见[计价](11-pricing.md#在用模型与新模型发现)。在用模型/全部模型与时间分布的渠道/模型/花销采用同一分段凹槽和选中按钮材质。免费规则、别名、继承字段和冲突状态分别说明。

## 模型输出吞吐（TPS）

**2026-10-20 界面移除：** 用户确认“按性能”不是 TPS 项目的实现路径，只是早期遗留入口，已从时间分布模式控件彻底删除：`#perfModeButton`、`#perfPanel`、`#perfDetailList` 及其渲染分支、样式与 `activeView`/`selectedPerfGroupKey` 状态一并移除。时间图只剩渠道/模型/花销三种模式。**数据侧保留**：`summary.perf.groups`、`src/perf-stats.js`、`src/perf-sources/*`、`public/perf-ui.js` 与对应测试不动，供后续独立吞吐区域直接消费；本页下文记录的是被移除入口的历史行为，不再描述当前界面。

**2026-10-08 界面反馈：** 用户已否决下述原版本入口与信息布局，并选定独立吞吐区域。具体原型及后续执行见[前端重构方案](plans/2026-10-08-tps-ui-restructure.md)；正式替换尚未进行。

原入口在时间图模式控件提供“按性能”按钮；进入后显示按来源、代理类别/名称、模型/provider 与 effort 分组的历史输出吞吐，同时沿用当前来源选择、日期范围及时区。指标为 TPS，不是 TTFT。请求端到端组会显示对应口径；Codex 组明确显示“轮级 item 时窗估算”和含 reasoning 的 token 范围。

性能面板提供 p10（较慢端）、p50、p90（较快端）、pooled TPS、时长分位数、样本量和覆盖诊断。pooled 是合并输出 token 除以合并时长，不表示日历时间的整体效率。每组至少 20 个有效样本才有排名；小样本仍可查看但不编号。没有有效样本时只展示原因，不造出 0 TPS。缺时间的候选标为“时间未定位”，说明来自当前选择来源的全历史，且不进入所选日期范围的 eligible 分母。来源未支持、读取退化、警告和待重建状态按其真实状态展示。

同一比较池按 p50 降序、稳定 group key 决胜；池内 provider/effort 只作为行标签，不另分块打乱排名，小样本行放在排名行之后。不同来源实例、渠道、代理和计时/token/window 口径不能混排比较。Codex 的 recent/legacy、估算与 subagent 有中英文标签；覆盖分母及其被剔除、待完成原因与有效样本数分开显示。

暂停自动刷新时性能查询沿用冻结快照；快照过期会显示错误并支持恢复，不悄悄用 live 数据替代冻结结果。实现、合成矩阵与真实 API→DOM 的证据入口见[最终审核包](validation/2026-10-04-perf-metrics/20261004T035100/final-audit.md)。

## 刷新与编辑

默认每 60 秒检查新记录。暂停自动刷新后，切换范围继续使用冻结的用量快照；恢复时沿用已有并发保护与轮询状态。用量轮询和价格的 24 小时刷新不是同一个计时器。

2026-10-10（U4）：**周期仍为 60 秒**；每轮先用 `since=<指纹>` 向 `/api/status` 做**内容检查**，只有内容真的变了（或当前是限额预设）才取数，**不得以少查来源换性能**（四类计数与周期 `skipCheck` 计数改前=改后，见[最终报告](validation/2026-10-09-refresh-performance-fix/2026-10-09T0525+0800/FINAL-REPORT.md)）。另修复一处"**首轮取数失败后永久停摆**"：失败的周期不再让后续周期永久跳过，自愈后恢复正常检查（自愈对照 0/0/0 → 1/2/3）。

价格弹窗修改草稿，只有保存才写入有效价目；取消保留原值。恢复自动汇率也遵守保存/取消约定。来源与计价弹窗保持焦点恢复和 Tab/Shift+Tab 边界；价格版本冲突由服务端返回明确错误。

## 语言、主题与材质

首次语言跟随浏览器首选，文/A 切换的选择被记住；提供中英文、浅色和深色。字体使用本机 Inter、Noto Sans SC 和系统回退，数字采用 tabular/lining；不加载外部字体。

陶瓷面板、槽底、边缘、高光与环境背景分开定义。环境背景最终为浅色 `#cfd8e1`、深色 `#20252b`；保持左上光源、标题凹字与槽内圆润分隔。输入值使用正文色，占位使用 muted 的 76% 混色；不同位置遵循相同语义。

标题以 38px/850 字重呈现同色凹刻，现有窄窗口规则为 32px；按最新追加要求，标题与右侧语言/主题区共用一个连续框体；两侧不再另设外框。标题行高为 1，采用 `text-box-trim: trim-both` 与 `text-box-edge: cap alphabetic` 裁切字体主体，再由 Flex 居中；不使用固定上移。现有窄窗口规则收紧横向间距和按钮宽度，容纳较宽的回退字体。最终主体上下留白见[标题像素验收](validation/2026-10-01-title-centering/README.md)。桌面工具栏采用三框布局：范围一列、自定义一列、自动刷新与时区一列，上下边缘对齐；刷新状态位于内部凹槽，开关紧邻文本；检查/更新用开关右侧预留的字高缺口圈每秒三帧旋转，不增加框体高度，失败时停圈并显示错误。关闭时只显示橙色“关”，不追加状态文字；冻结范围切换仍保持高度，见[关闭状态验收](validation/2026-10-01-refresh-off/README.md)。时间和异常可换行。时区及最近范围菜单沿触发外框左右边缘展开，共用外R15/内R10、13px/700字重及按钮材质；时区按钮至少112px，弹层按实际宽度适配。详见[加载圈与菜单验收](validation/2026-10-01-refresh-dropdowns/README.md)。空间收窄时换行，更窄时纵向排列，范围按钮两行呈现。趋势卡文案为“同比流速”。布局以实际浏览器检查为依据。

## 界面风格与角色

衣服图标打开“界面风格”（英文 Waifu）。选择器暂时提供 ChatGPT、Claude、DeepSeek、Kimi、Muse 五款皮肤，桌面五列一行，凹陷框随内容高度收缩；窗口可用宽度不足时自动换行，短窗口仅内部卡片区域滚动。每张卡片同时展示浅深缩略图，选中以与 New Record 同款的泛光圆点标识；不显示选中文字或底部色板。简洁模式位于标题右侧，关闭位于底部。角色开关、0—100% 透明度和皮肤选择保存在本机浏览器；简洁模式保留角色开关及透明度设置。自定义配色功能不纳入主程序。

角色默认透明度为 50%；左侧使用侧视线稿，右侧使用正视线稿，人物允许被框体遮挡，不为装饰压缩或重排功能区。位置根据真实看板外边界和左右留白中点，以各图的面部锚点仅作横向平移；空间不足时保护脸部不被屏幕边缘切断，保留静态降级。具体实现与测量见[居中验收](validation/2026-10-02-skin-face-centering/README.md)。

内部注册表仍保留十套角色、浅深共 40 张公开 WebP，当前选择器只提供五款。`skin-palettes.js` 为配色单一来源，浅深独立，classic 不加载角色；资源 manifest 和首屏脚本由准备命令生成。2026-10-20 新轮十套 900/900、关键几何 120/120、20 图 dense-data 复查及 classic/五款 picker/在线冻结通过，但整体仍为 incomplete：目标机 OS 缩放/browser zoom 经用户确认未测，最终全仓工程门禁待独立登记，延期五款未开放或发布；大视口整页高度差 +16px 单列保留，不表述整页完全相同。弱对比 Agent Usage 字标经用户确认保留，不当作遗漏；旧“配色待定”或“需十卡上线”状态不适用于当前要求。旧 production CLI 绑定旧迁移来源，见 [CLI 兼容调查](validation/2026-10-03-skin-palette-redesign/20261003T185748/integration/m62-reaccept-20261020/engineering-gates/cli-compatibility.md)，不作为本轮通过门禁。

## 框体聚光

主界面实际凸起框体和按钮使用当前主题强调色响应细指针光标；通常排除凹陷槽、输入控件与禁用按钮。整个日历浮层（含导航按钮、日期和间隙）不响应光晕。详情面板是例外：进度条轨道、填充、文字区域和条目间隙共用父面板的同一光层、坐标与半径，跨进度条边界不熄灭或重新渐显；光层覆盖轨道和填充，文字保持在其上方。动态重建的比较区与详情条目沿用事件委托，隐藏、弹窗和指针能力变化时清理状态，不改变原有几何与按钮按下材质。

当前强度为 22%，reduced-motion 保留指针跟随、取消渐显；不支持 hover/fine pointer 时降级。原始实现和专项验证见[聚光验收](validation/2026-10-02-frame-spotlight/README.md)，详情连续光晕修复见[详情聚光验收](validation/2026-10-03-detail-spotlight/README.md)，最终强度及组合复核状态只在[任务清单](02-tasks.md)维护。
