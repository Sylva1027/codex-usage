# 看板行为

更新：2026-10-01。追加的模型名单与连续顶部框体见[反馈验收](validation/2026-10-01-dashboard-feedback/README.md)，原九项修正的检查与截图见[本批验收](validation/2026-10-01-dashboard-corrections/README.md)，此前 UI 证据见[2026-09-30 验收](validation/2026-09-30-ui-pricing/README.md)。

## 时间范围与时区

今日、本周、本月、全部按选择的 local/UTC 解释；本周为自然周。最近范围中的上个月是完整自然月，本年从 1 月 1 日到当前时间。“上一个 5h”“上周”则是上一完整 Codex 限额窗口，不能将它们解释成普通日历周期。

`5h / week` 在当前 Codex 五小时和每周限额窗口之间切换。没有可信边界或没有选中 Codex 来源时，不凭空推算对应限额能力。五小时图按半小时、每周图按连续 24 小时显示。

日期控件按起止范围选择，支持反向点选、清除和 Escape。时区下拉位于刷新框内右上角，复用最近范围菜单材质；支持方向键、Home/End、Enter、Escape、Tab、外部点击和选后焦点返回。local/utc 选择持久化，上海本地显示 GMT+8；切换同时影响范围解释与上次刷新时间。长范围可自动合并为周/月时间桶，图表文字和 tooltip 标明实际覆盖区间。

## 用量、费用与周期对比

输入总量、缓存命中、缓存未命中、输出和推理使用[统一口径](10-data-sources.md)。费用按[当前有效价目](11-pricing.md)展示；模型显示名称统一小写，原始标识仍用于统计和解析。

模型与仓库支持搜索、周期对比和适用的 New Record。全部范围没有上一周期，不显示对应纪录徽标。仓库表首先展示本地 Git 仓库，这条规则高于所有周期用量和手动升降序；普通目录在后。

仓库表在 Git/非 Git 各组内、模型表在全表内，默认依次按今日 → 本周 → 本月 → 全部降序，平手时按名称和稳定原始标识；手动表头三态切换以所选周期为组内主键，平手按其余默认周期决胜，恢复默认后重新使用四级顺序。

## 来源与模型分组

扫描目录的“编辑”提供导入和来源选择入口，顶部不再重复放置导入按钮。来源选择控制哪些目录进入统计，不改变目录类型；内部 main 的徽标显示为 codex。普通范围按产品整合渠道，限额范围保留细分，详见[渠道口径](10-data-sources.md#渠道展示与归组)。Codex、ZCode、DSH、OpenCode 的计价模型按固定 harness 顺序分组；同一价目键先到先得，避免重复编辑。一个 harness 分区为空可能是模型已被前面的分区认领，不等于没有该来源用量。

近一个滚动日历月内使用的缺价模型仍显示在在用列表，不因无法解析到价目而消失；退出与覆盖率规则见[计价](11-pricing.md#在用模型与新模型发现)。在用模型/全部模型与时间分布的渠道/模型/花销采用同一分段凹槽和选中按钮材质。免费规则、别名、继承字段和冲突状态分别说明。

## 刷新与编辑

默认每 60 秒检查新记录。暂停自动刷新后，切换范围继续使用冻结的用量快照；恢复时沿用已有并发保护与轮询状态。用量轮询和价格的 24 小时刷新不是同一个计时器。

价格弹窗修改草稿，只有保存才写入有效价目；取消保留原值。恢复自动汇率也遵守保存/取消约定。来源与计价弹窗保持焦点恢复和 Tab/Shift+Tab 边界；价格版本冲突由服务端返回明确错误。

## 语言、主题与材质

首次语言跟随浏览器首选，文/A 切换的选择被记住；提供中英文、浅色和深色。字体使用本机 Inter、Noto Sans SC 和系统回退，数字采用 tabular/lining；不加载外部字体。

陶瓷面板、槽底、边缘、高光与环境背景分开定义。环境背景最终为浅色 `#cfd8e1`、深色 `#20252b`；保持左上光源、标题凹字与槽内圆润分隔。输入值使用正文色，占位使用 muted 的 76% 混色；不同位置遵循相同语义。

标题以 38px/850 字重呈现同色凹刻，手机为 32px；按最新追加要求，标题与右侧语言/主题区共用一个连续框体；两侧不再另设外框。标题行高为 1，采用 `text-box-trim: trim-both` 与 `text-box-edge: cap alphabetic` 裁切字体主体，再由 Flex 居中；不使用固定上移。手机收紧横向间距和按钮宽度，容纳较宽的回退字体。最终主体上下留白见[标题像素验收](validation/2026-10-01-title-centering/README.md)。桌面工具栏采用三框布局：范围一列、自定义一列、自动刷新与时区一列，上下边缘对齐；刷新状态位于内部凹槽，开关紧邻文本；检查/更新用开关右侧预留的字高缺口圈每秒三帧旋转，不增加框体高度，失败时停圈并显示错误。时间和异常可换行。时区及最近范围菜单沿触发外框左右边缘展开，共用外R15/内R10、13px/700字重及按钮材质；时区按钮至少112px，弹层按实际宽度适配。详见[加载圈与菜单验收](validation/2026-10-01-refresh-dropdowns/README.md)。中屏换行，手机纵向排列，范围按钮两行呈现。趋势卡文案为“同比流速”。布局以实际浏览器检查为依据。

## 静态快照的区别

静态 HTML 可切换语言、主题、范围、搜索与时区，但不轮询、不更新服务器、不保存价目或导入来源。需要新数据时重新导出，详见[导出约定](13-static-export.md)。

已有浏览器检查覆盖合成数据的在线/离线布局和交互；真实来源专项、原生缩放与自动补录后的 UI 证据仍按[任务清单](02-tasks.md)区分。
