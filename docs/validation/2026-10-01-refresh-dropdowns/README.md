## 最终行为

检查/更新状态使用开关右侧预留的 1em 缺口圆环，`1s steps(3, end) infinite` 每秒三帧旋转；不再插入检查文字。成功、失败或关闭自动刷新时清空圈，失败提示仍显示并换行。字高及预留位置使检查期间框体高度不变。提供中英文可访问状态标签。

菜单不再使用固定宽度或右偏移。最近范围菜单与范围触发外框对齐，时区菜单与时区按钮对齐；时区按钮至少 112px，菜单按其实际宽度自动适配。两套菜单统一外 R15、内 R10，4px 内距与 1px 外边框保持同心，选项字号 13px、字重 700。通用分段按钮材质限定直接子按钮，避免再次覆盖菜单内圆角。
