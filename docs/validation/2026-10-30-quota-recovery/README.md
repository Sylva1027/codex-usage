# 当前 7d 边界恢复验收

2026-10-30。修复已接入正式服务；默认本地，只有单机明确授权后才按需官方只读补齐。不依赖 Magpie，不上传本机统计，不增加常驻说明框。

## 已确认根因

最新可用本机周窗口在北京时间 2026-10-30 01:26:03 到期，近期原生 rollout 的 `rate_limits.primary` / `secondary` 均为空。Token 仍在增长不代表新边界已经落盘，旧边界到期后当前 7d 因此返回 409；上一完整周期仍可查询。

性能部署前恢复点与正式库均有 67,290 条额度观测，规范逐行 SHA-256 均为 `7b4c4e0b2bb185adb144968b9fb2db186d97568d00c121a349aff286d3507bec`。不是部署丢失观测，也不是把 primary 固定解释为 5h 导致本次缺窗。

安装引擎日志显示忽略 `codex.rate_limits`；较早版本参考源码的 HTTP SSE 路径也缺对应分支。二者版本不同，且未保存真实上游额度原始载荷，只能确认本机缺乏新窗口记录，不能把参考源码当成安装二进制的完整证明。

## 修复边界

- `src/codex-quota-cache.js` 默认 `recoveryEnabled: false`。本机私有 `~/.codex-usage/codex-quota.json` 明确设置为 `true` 后，仅请求当前 5h/7d 且本机窗口缺失或等待新周期时触发官方客户端只读查询。
- 有效窗口、已确认套餐不提供该窗口、旧冻结快照、导入运行时和歧义证据不触发查询。失败持久化冷却五分钟，同进程同缓存路径并发合并；恢复成功后当前 HTTP 请求最多重算一次。
- 官方客户端管理凭据；临时 app-server 和 SQLite 目录在结束后回收。只保存规范额度、观测时间和哈希账户标识，不保存凭据、邮箱或原始账户 ID。
- 本地规范观测进入内存报告、SQLite `store_meta.official_quota_observations` 与冻结数据。汇总签名仅受规范额度变化影响，不受重试时间影响；缓存有效期在真实 reset 截断。过期窗口不数学续期。

## 已完成验证

前轮 115 项服务端、Store、额度及缓存检查通过。整理发布时复跑包含三路一致性、缺窗恢复、默认离线、冷却、并发、重启复用、冻结与过期失效的定向检查，结果见[v0.8.0 发布记录](../2026-10-30-release/README.md)。测试使用隔离本机夹具，不找用户不存在的 credits 历史。

真实获准查询返回 `prolite`，只有 primary 10,080 分钟，reset 为北京时间 2026-11-04 14:38:50；由 reset−duration 得起点 2026-10-28 14:38:50。正式请求自动补齐后，7d / 5h / 7d 依次返回 200 / 409 / 200，官方尝试时间和快照数不变；无 5h 不会发明窗口或反复查询。SQLite 观测与本地缓存投影相等，真实页面三张趋势卡恢复正常，当前模型仅包含 GPT 模型。
