## 更新内容

- 支持 Codex、ZCode、DSH 和 OpenCode 本地用量来源，并完善导入、周期统计和静态快照。

## 升级

下载本版本源码或拉取 main，停止旧服务后重新运行 `node src/cli.js run`，再刷新页面，以启用新版模型活动字段。需要 Node.js 23.8 或更新版本；运行看板无需安装 npm 依赖。
