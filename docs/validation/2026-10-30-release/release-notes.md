- 轻量常驻 HTTP 服务，重计算按需启动并空闲退出；持久化本地汇总可在刷新和重启后复用。
- 精简 DSH 解析和性能字段保留，降低索引检查、样本读取和历史汇总的临时分配；保留完整内容校验，避免已确认缺失历史依赖的重复复建。保持 Node 技术栈，未接入 Rust。
