## 界面风格 / Waifu

- 新增角色皮肤选择器，目前提供 ChatGPT、Claude、DeepSeek、Kimi、Muse 五款皮肤；支持简洁模式、角色显示开关和透明度调整。
- 同时预览浅色与深色方案，桌面五款一行，凹陷框随内容高度收缩，窄屏自动换行；选中使用泛光小圆点。
- 皮肤配色联动整页材质，立绘按实际看板留白定位；首屏恢复偏好，离线 HTML 内嵌全部角色资源。
- 修缮标题材质、按钮及框体聚光交互；中文最近范围选项更新为“上一个7d”，英文保持 Last 7d。

## 计价与稳定性

- 纳入 v0.5.0 之后的 Claude 价格与缓存写入处理修正，保留缺价和不支持 TTL 的明确提示。
- 保留已有统计、来源、语言和静态导出能力；自定义配色编辑器不纳入主程序。

## 验证与获取

- 发布前运行完整测试、类型、Lint、格式及皮肤资产／配色检查，并验证五款皮肤的在线与禁网离线交互。
- GitHub Release 提供源码 ZIP / TAR；运行要求仍为 Node.js 23.8 或更新版本。
