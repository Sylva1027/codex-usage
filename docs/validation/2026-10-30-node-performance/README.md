# Node 性能优化正式接入验收

2026-10-30。已应用的优化整理入库；不接入 Rust、不增加依赖、功能或 UI。保留轻量常驻服务、可退出计算进程与持久化汇总架构。

## 实现范围

- DSH 流式解码在异步交接前投影统计所需字段，避免保留正文及完整流对象；公开完整行读取接口保持原行为。
- Codex 完整前缀哈希与头尾探针合并读取，大 home 用同计算器内两个异步 reader，避免额外 Worker 堆；完整校验、归属及前后稳定性检查保留。
- SQLite 性能样本迭代读取、旧集合消费后释放，跳过无 session 变化时的重复查询。
- 已成功发布并确认缺失的历史依赖仍缺失时复用候选；新缺失、文件返回、内容或身份改变仍触发重建。
- 历史冠军计价使用现有请求内模型字典；同一汇总读事务只读取一次额度观测。

## 正式服务测量

以修改前 `cf1c970` 源码副本为基线，与新版在同一正式索引上串行轮换三次。输入自然前进，汇总首请求均未命中；不是冻结输入速度竞赛。父服务 old-space 128 MiB、计算器 old-space 224 MiB / semi-space 4 MiB，未提高内存预算。CLI 默认父堆仍为 512 MiB；堆预算不是总进程内存上限。

- 首响基线 25.069 / 24.652 / 13.159 秒；新版 23.627 / 22.246 / 20.514 秒。中位数 24.652→22.246 秒，约减少 9.8%；第三轮新版更慢，不能宣称稳定提速 30%。
- 同一时刻服务与全部计算进程之和：工作集峰值中位数 353.98→301.21 MiB；Private Bytes 峰值中位数 366.46→306.71 MiB。
- 另一次新版完整流程：今日 10.508 秒、固定历史 10.175 秒、全部 10.236 秒，均 HTTP 200；三次检查式刷新 21.234 / 22.150 / 23.884 秒，均未命中且启动计算器。
- 完整流程工作集峰值 341.46 MiB、Private Bytes 355.97 MiB。结束后五秒短待机峰值 87.50 / 96.42 MiB；不是长期待机分布。
- 本轮目标进程树采样均低于 512 MiB，不能排除短于采样间隔的尖峰。旧版一次全部查询退出码 134，但未捕获 stderr，不能仅凭退出码断言 OOM。
