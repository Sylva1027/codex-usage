2. **Main 的最小接点**：`perfPublicationState()` 返回 `magpieTimingFingerprint`（缺失 meta 为 `""`）；`sync()` 返回的 `status.magpieTimingFingerprint` 反映本次结果对应的已确认值，包括 enrichment 失败而 native 发布成功时的旧确认。该字段需在性能发布之后确定，不能沿用 enrichment 前的中间 status。W2 不改 store。

4. **W2 / executor**：`postState()`、`emptyState()` 与读侧 getter 传递已确认字段（拟命名 `magpieTimingFingerprint`）。`perfPublicationState` 请求已原样返回 store 结果；`sync`/dashboard/publishedStatus/快照沿对应 status 传递字段。崩溃重启清空快照，既有有界恢复逻辑保留。
5. **W2 / usage**：默认 dashboard 指纹取 `result.status || usage` 的 acknowledged 值，不能在返回前取最新 perf state 替代。full detail 也取其 `indexedStatus` 的 acknowledged 值。`skipCheck=1`/内部 `check:false` 不确认新 ledger；不新增开关或 `check=off` HTTP 参数（当前接口只有 skipCheck）。冻结指纹取快照 status，优先使用 executor 随备份返回的 `frozen.status`，不能再 stat ledger 或读取 live 确认值。
